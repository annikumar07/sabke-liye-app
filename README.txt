SABKE LIYE — how to put it online (free, about 2 minutes)

OPTION A: Netlify Drop (easiest, no coding)
1. Unzip this folder.
2. Open https://app.netlify.com/drop in a browser.
3. Drag the whole "sabke-liye-app" folder onto the page.
4. You get a link like https://something.netlify.app. Sign up for free (or log in)
   so the site stays online, then change the name under Site settings,
   for example https://sabke-liye.netlify.app

OPTION B: GitHub Pages
1. Create a new public repository on github.com (e.g. sabke-liye).
2. Upload ALL files from this folder (Add file > Upload files) and commit.
3. Settings > Pages > Source: "Deploy from a branch", Branch: main, folder: / (root) > Save.
4. After about a minute the link appears: https://<your-username>.github.io/sabke-liye/

INSTALL AS AN APP
- Android (Chrome): open the link > tap "Install app" in the page, or menu ⋮ > Add to Home screen / Install app.
- iPhone/iPad (Safari): open the link > Share > Add to Home Screen.
- Computer (Chrome/Edge): click the install icon in the address bar.
It then opens full-screen with its own icon and also works offline after the first visit.

Note: Do not open index.html by double-clicking to share it. Always share the website link.
